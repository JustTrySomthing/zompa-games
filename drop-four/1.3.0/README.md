# Cats vs Dogs

This LÖVE port replaces the downloadable Drop Four game as build 6 of the same game ID. Archived builds stay available for existing matches and links. The current Zompado client supplies the authoritative board and sends moves over Chatmail. Cats play first online. Solo play lets you pick a team and difficulty. Solo and pass and play are first-to-three and retain progress across launches. The game can resume a Drop Four move history saved by an older build.

Original portraits, faceoff art, music, and effects came from [OnKlav Cats vs Dogs](https://github.com/JustTrySomthing/OnKlav/tree/58bf9d93711f8babcccf91875c1e0b1de0a1a57d/games/engine-checks/cat_dog). The portraits and faceoff were converted from WebP to PNG for the embedded LÖVE decoder. Source assets are bundled in this directory so release builds work without fetching another repository.

Run this directory in LÖVE 11.5 for solo play or install the official .zomp in Zompado to access pass and play and Chatmail matches.
