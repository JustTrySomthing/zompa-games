# Cats vs Dogs 1.3.13

Cats vs Dogs is the Zompa SDK reference game for Single Player, Pass & Play, and Online 2 Player. It uses the shared SDK for mode selection, music and effects, local session saves, and the game-to-player online handoff. Its board, computer opponent, and rendering live in the game. Zompa supplies the toolbar, pause, help, and encrypted Chatmail match transport. The old save reader exists for upgrades from published builds.

See [the SDK guide](https://github.com/JustTrySomthing/zompa/blob/main/sdk/README.md) for the package and Android publishing checks.
