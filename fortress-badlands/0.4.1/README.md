# Fortress: The Badlands v0.4.1 — approved board build

7×10 square grid, 58 playable cells and exactly 12 absent stepped-corner cells. 14 troops and one squat Fortress per kingdom. Blue top, burgundy bottom; fortress remains centered. Four neutral middle rows. No square is clipped or rescaled. Player 1 at bottom.

Uses the approved Nov 23 image as an asset source for real movable hex badges, aged-stone board and bastions. Art is rasterized and cropped, not redrawn from freeform generation. Single action/turn; tap a reachable occupied square to preview and attack, win to land there. D8 winner fixed-hit dice, persistent HP, potion 4–10, 35 HP Fortress (D8, hit 5), simultaneous D8 Final Siege with independent 7-point hits on 4–8.

Soldier 22HP / Move2 / Hit5 (4); Wizard 16/1/8 (2); Assassin 14/3/6 (3); Barbarian 19/2/6 (3); Ogre 28/1/6 (2). SDK v4, LÖVE 11.5, local save v4 and turns-v1 online. No old version changes; old saved games deliberately do not import because the roster, mask and unit ID count changed.

This version should be verified on Android in solo, local and online modes before publishing to Get Games.
